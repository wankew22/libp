# libp

Researchers developed B3clf, an open-source machine learning framework designed to predict the blood-brain barrier (BBB) permeability of small molecules. To address the common problem of class imbalance in chemical datasets, the study integrated four classification algorithms with six different resampling techniques, such as SMOTE and ADASYN. Their findings indicate that XGBoost combined with oversampling provides the most reliable and robust predictions for identifying permeable compounds. The models were validated against a newly curated external dataset, where they consistently matched or outperformed existing state-of-the-art computational tools. To assist in drug discovery, the authors released B3clf as both a Python package and a user-friendly web application for broad scientific access. Technical analysis further suggests that a molecule's electronic topological state and hydrogen bonding potential are critical factors in determining its ability to reach the central nervous system.

As of Apr 2026, the model is further validated with benchmark and external datasets. We are actively exploring the effect from multiple conformations, descriptors from rdkit and liten-ff on model's prediction ability.
